# memo-app テーブル定義

## memos テーブル
| カラム名 | 型 | 必須 | 自動で入る | 説明 |
|---|---|---|---|--|
|id|整数|〇|〇|メモに与えられる採番|
|content|文字列|〇| |メモの内容、200文字まで|
|created_at|日時|〇|〇|作成した日時|

## 採用しなかった列
- created_by(作成者):作成者を持たせるには「ユーザー」という別のものが必要になるため
- is_deleted(論理削除):元に戻す機能がある場合に便利だが現状は実装していないため

## ER 図(練習:ユーザーを作る場合)
```
users テーブル            memos テーブル
┌────┬────────┐          ┌────┬────────────┬─────────┐
│ id │ name   │          │ id │ content    │ user_id │ ← users の id を指す
├────┼────────┤          ├────┼────────────┼─────────┤
│ 1  │ kenta  │◀─────────│ 1  │ 牛乳を買う │ 1       │
└────┴────────┘          │ 3  │ 卵を買う   │ 1       │
                         └────┴────────────┴─────────┘
   1人のユーザーが、たくさんのメモを持つ(1対多)
```
