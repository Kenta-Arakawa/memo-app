# memo-app テーブル定義

## memos テーブル
| カラム名 | 型 | 必須 | 自動で入る | 説明 |
|id|整数|〇|〇|メモに与えられる配番|
|content|文字|〇| |メモの内容|
|created_at|date| |〇|作成した日時|

(content は200文字までと書く)

## 採用しなかった列
- created_by(作成者):...作成者を持たせるには「ユーザー」という別のものが必要になるため
- is_deleted(論理削除):...元に戻す機能がある場合に便利だが現状は実装していないため
